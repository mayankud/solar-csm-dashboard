# Mayank Udaywal · Velunora Solar — Customer Success Dashboard

A standalone interactive dashboard prototype for monthly service-order tracking.

## Open

Open `index.html` in a modern browser. No installation, server, API credentials or build step is required.

## Features

- Client → service → monthly order counts, client totals and year-to-date totals
- Client and service filters, expandable rows and CSV export
- Rule-based risk indicators, delivery holds and recovery examples
- Responsive layout and metric definitions

## Data and privacy

All embedded records are synthetic demonstration data. Client codes and CSM aliases are arbitrary and do not map to real organizations or people. The prototype contains no production customer records, account credentials, private endpoints or live data connections. Filters and exports run in the browser. CSV exports are labeled as illustrative.

This is a demonstration, not a production reporting integration. Replace sample records only within an appropriately secured deployment.

## Repository contents

Only the sanitized dashboard and this documentation belong in this repository. The original development history, hosting configuration, deployment archives, screenshots and temporary files are intentionally excluded.
