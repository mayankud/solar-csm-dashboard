# Third-party components

Dependencies are pinned and bundled locally from the npm registry. No CDN is contacted at runtime.

| Component | Version | Upstream | License file |
| --- | --- | --- | --- |
| Chart.js | 4.5.1 | https://www.chartjs.org/ | chart.LICENSE.md |
| Papa Parse | 5.7.0 | https://www.papaparse.com/ | papaparse.LICENSE |

The library files are unmodified distribution builds. The project does not bundle library source maps. Retain the license files when distributing the dashboard. Dependency updates should be followed by chart, CSV import and export checks.
